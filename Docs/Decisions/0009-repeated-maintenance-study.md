# ADR 0009: repeat a dependency/evidence task, then build an end-to-end workflow

Accepted 2026-11-09. Follow the first pilot with an independently agent-authored pallet-admission scenario, three fresh repetitions per arm, seeded counterbalanced order and strict TypeScript/BigInt plus real compiler-derived context tooling. Freeze inputs/tools before attempts and lock finals before scoring. No runtime or language changes.

Both arms passed three repetitions, 547 finite full-Decision invocations each. Report matching history assertions separately from actual acceptance. Preserve all original evidence and the prior pilot failure. No measured token/latency advantage, causal superiority, external-user validation, production-repository or large-context claim.

Missing features can limit usefulness; a feature freeze was temporary, not a demand that today's prototype already compete everywhere. Classify capability gaps separately from friction/design disadvantages. Further benchmark accumulation is not the immediate product goal. Next: an agent-facing policy-change workbench with structured cases, revision-linked decision differences and explicit review, adding only necessary capabilities.
