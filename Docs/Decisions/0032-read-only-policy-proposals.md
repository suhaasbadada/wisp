# ADR 0032: One caller-pinned maintenance command

Status: implemented; full local checks, exact proposal CI commands and independent
review passed. Exact-head Linux CI/publication pending.

Coordinate existing context, guarded preparation and exact saved-case review in a
standard-library driver, not another language/MCP feature. Require an explicit
caller guard before focus/body IO; derive body identity only from Rust graph
metadata. Preserve stage outcomes, exact candidate identity and unchanged cases.
Never refresh pins, repair expectations, persist candidates, Apply or approve.

The frozen demonstration pins the existing faulty reservation baseline and uses
its existing corrected body. CI checks Pass7/Changed2/14attempts and retains full
proposal evidence. This is one authored example, not an independent agent trial,
performance comparison or adoption. Reports contain source/case data; context text
budgets are not aggregate memory/time/output bounds. Trusted-host and finite
evidence limitations remain. See [proposal contract](../Policy-proposals.md).
